## Selected work

### Study Quest
**Next.js 16 · TypeScript · Gemini · RAG · Local-first storage · Tailwind CSS · NextAuth**

A 100% local-first AI study planner and productivity suite. It generates grounded study schedules with Gemini, provides an AI tutor with optional live web-search augmentation through Tavily, creates interactive Markmap mind maps, and includes Pomodoro focus sessions, ambient sound, a 28-day consistency heatmap, wellness scoring, study journaling, and CSV export. Application data is persisted in a local atomic document store rather than a cloud database. [Repository](https://github.com/theprachurya/study-quest)

### PageTurn
**Next.js 16 · React · TypeScript · Supabase · PostgreSQL · epub.js · PWA · IndexedDB**

A browser-based EPUB reader, library manager, and reading-analytics application. Implements EPUB rendering, highlights, bookmarks, shelves, tags, reading sessions, statistics, offline caching, queued offline actions, and cross-device reading-progress synchronization through Supabase Realtime. [Repository](https://github.com/theprachurya/PageTurn)

### Saveur Restaurant OS
**JavaScript · Supabase/PostgreSQL · Vercel**

A restaurant ordering and management application with separate customer and owner workflows, menu and cart management, order history, inventory tracking, revenue views, feedback, notifications, stock-safe ordering, low-stock alerts, and an in-browser QA test screen. [Repository](https://github.com/theprachurya/saveur-restaurant-os)

### AI Study Planner
**Python · Flask · SQLite · Gemini · JavaScript**

A full-stack study-planning application that generates personalized learning guides and schedules from subjects, dates, study hours, commitments, difficulty information, and optional assessment marks. Includes calendar-based schedule views, SQLite persistence, resilient JSON handling, and fallback schedule generation when AI output is unavailable or malformed. [Repository](https://github.com/theprachurya/AI-Study-Planner)

### Ambient Study Companion
**Python · Flask · SQLite · Docker/Podman · JavaScript**

A productivity companion with ambient soundscapes, Pomodoro timers, reminders, wellness logging, notifications, profile switching, CSV exports, and accessibility features including keyboard navigation, text-to-speech, font controls, ARIA labeling, and screen-reader support. [Repository](https://github.com/theprachurya/Ambient-Study-Companion)

### Web Novel Tracker
**Vite · JavaScript · Supabase**

A lightweight novel-library tracker with search and status filtering, reading-progress tracking, admin CRUD operations, Supabase persistence, and automatic cover lookup through AniList, Jikan, and Google Books APIs. [Repository](https://github.com/theprachurya/web-novel-tracker)

### Safar
**Web application · Recommendation logic**

A train-ticket booking concept that addresses waitlisted tickets by recommending alternative stations where a user can book and still board from the intended station. [Repository](https://github.com/theprachurya/safar)
